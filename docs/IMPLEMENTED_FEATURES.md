# VHS6RIFT — Source Feature Inventory (Repair Pass)

This inventory reflects the current source, not a claim that every stage has been compiled or visually verified in After Effects.

## Core VHS signal path

- Fixed VHS transfer response; the selectable camera/color engine and its tuning banks have been removed.
- NTSC-RS is called through the included Rust C-FFI wrapper, with independent enable and controls for chroma delay, head switching, edge wave, and composite noise.
- Color/chroma controls, luma softness, chroma bleed/offset, signal noise, tracking, and tape dropouts remain separate stages.
- Signal engine controls have separate enable gates for VHS Craft-style tracking/chroma/head-switch/smear, VHS Legend-style breakdown/tear/loss/corruption, NTSC-RS, and Signal Reference.

## Moving grain

- Moving grain is time/seed-driven and sampled with interpolated noise to avoid coarse block-shaped cells.
- Grain amount defaults to a clearly visible level; size, softness, structure, color mode, and manual RGB controls remain available.
- Actual visual grain texture and render performance still need testing with the compiled plugin at common AE resolutions.

## Tape behavior

- Tape model selector includes Off, Horizontal Band, Bottom Head-Switch, Vertical Roll, Side Tear, and Signal Snow.
- Models include animated band-edge irregularity, signal/luma loss, chroma displacement, vertical source displacement, and moving snow.
- Tape behavior defaults to Off so the default image receives the core VHS signal without additional tape-damage layers unless enabled.

## Overlays and Glitch Cam

- Overlay source selection is no longer a layer input. A single yes/no control enables the built-in procedural overlay library directly on the source footage.
- The overlay library contains 21 procedural animated artifact styles; these are generated by code, not copied GIF frames.
- Glitch Cam is a separate opt-in event stage with event style, amount, chroma split, block size, rate, color palette, and blend-in controls.
- CRT TV controls and the CRT system have been removed from the UI/source per the requested scope reduction.

## Verification status

- `python tools/validate_project.py`: static parameter registration and required-control checks.
- `python tools/audit_parameter_wiring.py`: static ID wiring checks.
- `python -m pytest -q`: Python source/model tests.
- The Rust static library and native C++ render harness have not been built/run in this environment because Cargo and the complete licensed AE SDK/PiPLtool are unavailable. No AEX build or After Effects visual test is claimed.
